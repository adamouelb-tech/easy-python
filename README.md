# easy-python
Small and beginner-friendly Python scripts and mini-projects.

## Play the games

Clone or download this repository, open a terminal, and go to the project folder:

```bash
cd easy-python
```

Start the game menu:

```bash
python3 main.py
```

Choose a number from the menu and press Enter. The available games are Blackjack, Wordle, Calculator, Rock, Paper, Scissors, and Number Guessing. To leave the menu, choose `0`.
